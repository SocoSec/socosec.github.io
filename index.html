About

I'm a cybersecurity engineer from Socotra, Yemen, currently in Budapest on a Stipendium Hungaricum scholarship for my M.S. in Cybersecurity at Óbuda University (4.83/5.0 first semester). Before that: a dual B.Sc. in Software Engineering (AASTMT & University of Northampton, First Class Honours), two years as a Network and Information Security Specialist at Al Muthalath Al Sharqi Holding, and penetration testing training at Security Meter Academy in Cairo. I work with SIEM tools, IDS, packet analysis, and the MITRE ATT&CK framework on the defensive side, and network and web-app penetration testing on the offensive side — with Python, Java, Go, and C++ underneath. Certifications include Certified Cyber Security Analyst (Cyberwarfare Labs), Google Cybersecurity Professional, CCNA, and Cyber Threat Hunting (Infosec). The digest above is generated daily by a small agent I run on GitHub Actions — allowlisted sources only, always linking to the original report.
